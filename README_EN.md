## 📌 Project Overview

This project is a comprehensive **AI-powered video localization and secondary creation workflow system** designed for content creators, studios, and enterprise teams. It enables users to efficiently complete multilingual video translation, dubbing, and synthesis.

The system integrates the following workflow components:
- Automatic Speech Recognition (ASR)
- Large Language Model subtitle understanding and rewriting
- AI Text-to-Speech (TTS) synthesis
- Audio-video timeline alignment and composition

Emphasizing **high quality, localized expression, batch processing capabilities, and scalable architecture**.

## 🚀 Core Features

### 🎙️ Speech Recognition (ASR)
- Support for long-form video speech recognition  
- Multilingual input support  
- Stable timeline output  

### 🧠 Intelligent Subtitle Optimization
- Context understanding based on large language models  
- Subtitle refinement with colloquial, dramatic, and localized expressions  
- Preserves original video tone and emotion  

### 🗣️ AI Dubbing (TTS)
- Multiple voice styles and tones  
- Adjustable speech rate, intonation, and emotion  
- Character voice mapping support  

### 🎬 Video Synthesis
- Automatic alignment of subtitle and dubbing timelines  
- Automatic mixing of dubbed audio with background music  
- One-click final video generation  

### 🔁 Workflow-Driven
- Modular node design  
- Batch task processing support  
- Easy extensibility for new capability nodes
