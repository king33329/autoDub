# AutoDub 使用教程

欢迎使用 AutoDub 二创工具！本工具通过 AI 技术赋能，帮助短视频创作者提高内容制作效率。

## 版本说明

AutoDub 提供三个版本：

- **免费版**：基础功能，适合入门用户【仅需一个梯子即可，无任何其他成本】。不限制短视频生成额度
- **付费版**：付费版解锁更多功能权限【基本脱离人工，全自动化生成到发布】，每天半小时即可完成副业

## 安装

1. 从123云盘 下载软件安装包
2. 解压压缩包（无需安装）
3. 双击运行 `AIUP.exe` 启动程序
